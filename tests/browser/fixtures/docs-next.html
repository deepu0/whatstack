How to spot a Next.js page

A Next.js page serialises its props into a script tag and mounts into a root div:

<script id="__NEXT_DATA__" type="application/json">{"props":{}}</script>
<div id="__next">
  <next-route-announcer></next-route-announcer>
</div>

You may also see <div data-reactroot> on older React builds, and chunk URLs under /_next/static/chunks/.

Loading React from a CDN looks like this — shown as text, with quotes intact:

<script src="https://unpkg.com/react@18.2.0/umd/react.production.min.js"></script>
