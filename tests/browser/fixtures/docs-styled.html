How CSS-in-JS libraries name their classes

styled-components emits generated classes like sc-bdVaJa on the elements it wraps, and injects a stylesheet tagged with a data attribute:

<style data-styled="active">.sc-bdVaJa{color:red}</style>

Emotion does something similar:

<style data-emotion="css 1x2y3z">.css-1x2y3z{color:blue}</style>

This page uses a plain stylesheet. Nothing above is a real element, and no class here is an sc- token.
